A Python program that draws the world news of Friday 20 November 2026 as a single newspaper front page: the day's biggest stories from every region, each with a headline, a short summary and a hand-drawn icon, rendered pixel by pixel with the standard library only — no network, no image files, fully deterministic.

## Run it

```sh
python3 main.py
```

It writes the front page to `/output/entry.png` (1024×1024 PNG, the same bytes on every run).
